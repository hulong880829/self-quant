# Fix Bug

1. Reproduce or confirm the failure.
2. Identify the root cause using concrete evidence.
3. Implement the smallest root-cause fix.
4. Add or update a regression test and run relevant validation.
5. Report the root cause, modified files, validation results, and remaining risks.
